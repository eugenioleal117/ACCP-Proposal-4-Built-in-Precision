# Built in Precision — ACCP Construction

**Proposal 04.** A colder, more industrial evolution of *In Good Light*. The original ACCP skyline is retained, with Midnight, Structural Blue, Blueprint Cyan, Steel and Chalk. No orange.

[View the proposal](https://eugenioleal117.github.io/ACCP-Proposal-4-Built-in-Precision/)

## Included

- Cinematic blue-hour architectural cover, compressed display typography and restrained editorial motion.
- An original 18-second HyperFrames construction film: site, foundations, structure, concrete envelope, glazing, roofs, landscaping and completed house. Pause, replay, progress and phase controls.
- Four architectural studies with category filters and a keyboard-accessible gallery dialog.
- Brand studio: original logo, three color applications, copyable palette, typography, six construction icons and five social style specimens.
- Chevrolet Silverado, business card and field-polo applications.
- Persistent dark/light theme, mobile navigation, reduced-motion support and two-step local inquiry demonstration.

## Run locally

Serve the repository root with `python3 scripts/serve.py`, then visit `http://localhost:8784/`. GitHub Pages serves `/` on `main`. The local preview supports byte-range requests for video seeking in Safari. No build or backend is required. Website fonts, images and film are local. The site makes no external runtime requests.

## Construction film

The film is an original architectural motion graphic, **not recorded job-site footage**. Its house is a conceptual study rather than the exact building in the cover photograph. It is silent by design for website use; playback is muted and inline. It starts once on entering view, pauses offscreen or when the page is hidden, and does not autoplay with reduced motion enabled. User pause and manual seeking take priority over autoplay.

Source: `motion/index.html`, generated by `python3 scripts/build-motion.py`. It has one deterministic paused GSAP timeline registered as `construction`. To verify or re-render with Node.js 22+, npm and FFmpeg:

```sh
npm run check
npm run motion:check
npm run motion:render
```

HyperFrames is pinned to `0.9.67`. A completed-house poster is included for the pre-play and reduced-motion experience.

## Content and assets

All architecture and mockups are illustrative concept imagery, **not a claim of completed ACCP work**. The cover was generated specifically for this direction with the built-in ImageGen tool. Supporting illustrative mockup and atrium assets were reused from proposal 02 with a grayscale/blue presentation treatment; the original logo and its mask come from proposal 03. No partner logos, reviews, project statistics or client claims were invented.

The inquiry is a local prototype: browser validation, two steps and completion feedback. It sends nothing, stores no contact entries and clears the fields when closed. A real inquiry delivery service is outside this concept.

Inter and Barlow Condensed are distributed under the SIL Open Font License; license files are in `assets/`. GSAP's bundled header and README are retained. ACCP artwork remains the property of its owner. This repository does not grant rights to ACCP's identity.
