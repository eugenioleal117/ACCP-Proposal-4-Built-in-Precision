# ACCP / Fachada / Brand resources

Approved direction B, developed as the fourth proposal identity. Includes master SVGs, transparent PNGs, positive and reversed signatures, avatars, small-size/web icons, fonts with licenses, palette and PDF usage guide.

The logo itself spells ACCP. Use the stacked signature for primary presentation, the horizontal signature in wide formats, and the small-size cut for 16-32px icons. Refer to GUIA-DE-USO.md for clear space, minimum sizes and color reproduction.

This download excludes the earlier illustrated application studies. Photographic applications on the proposal website were remade separately with the new identity. CMYK values are unprofiled references; verify with your print supplier.
